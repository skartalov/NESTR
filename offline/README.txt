NESTR - standalone offline version
==================================

No installation, no Node.js, no server, no login.

1. Copy this whole "offline" folder anywhere (USB stick, another PC, Windows XP...).
2. Double-click index.html (opens in your default browser).

Browser requirements: any browser with SVG support. On Windows XP use
Firefox 52 ESR or Chrome 49 (the last versions for XP).

Features are the same as the web version: nesting, PDF (Print / Save as PDF),
and G-code export (X, Y, A, M20/M21, M30), one .txt file per sheet saved to the
browser's download folder.

If the browser asks where to save files, or blocks multiple downloads,
allow them for this page.
